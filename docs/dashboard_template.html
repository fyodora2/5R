Search & screening — five databases

Europe PMC (field TITLE_ABS, four AND'd concept groups): 227 raw → 213 unique → automated screening on MEDLINE pubType + design language + occupational-population terms → 85 include / 32 uncertain / 96 exclude.

OpenAlex (same query, personal API key, title_and_abstract.search): 716 raw → 315 not already found via Europe PMC → 46 automated include → manual reconciliation (removed conference-abstract companion reports, a protocol, a mis-screened systematic-review registration, internal duplicate indexing) → 30 new studies.

ERIC (tests whether teacher-focused studies were an Europe-PMC-specific gap): 8 candidates → 7 excluded (in-person delivery or student-only population) → 1 new study.

Web of Science (official export, own institutional access, same four-concept query on the Topic field): 352 raw → 274 not already found → 34 automated include → manual reconciliation excluded 14 trial protocols (a systematic issue: protocol abstracts describe a planned control arm in future tense, which satisfies the same regex a completed trial does) plus 2 false positives → 18 new studies.

Scopus (own institutional access; the official bulk export was unavailable, so only a title/year/source capture of the visible results — no abstracts — could be retrieved): 382 raw → 284 not already found. Since Scopus provided no abstract, each new title was resolved against OpenAlex by title match (201 resolved, 83 unresolved); one further record with no abstract anywhere was resolved via its ClinicalTrials.gov registration. 24 automated include on the resolved abstracts → manual reconciliation removed duplicates of the same trials already excluded/included via WoS or Europe PMC, two more reviews, and one more protocol → 5 new studies.

A supplementary ClinicalTrials.gov registry check (24 precisely-matched interventional trials, 16 completed, only 2 with results posted to the registry) is a publication-bias signal, not folded into the corpus.

Data handling note: Web of Science and Scopus license terms restrict bulk redistribution of their records. This dashboard and the companion repository therefore keep title/year/DOI/journal and this project's own coded tags for those 23 studies, but not their original abstract text.

Limitations

No PsycINFO or Cochrane CENTRAL access from this environment. Screening included one manual reconciliation pass per database beyond Europe PMC, not a full independent dual-human review. Coding is abstract-level only (or, for one Scopus record, a trial-registry synopsis), so technology/instrument/comparator fields are frequently "unspecified." Clustering silhouette is low, reflecting a topically homogeneous corpus — read cluster themes qualitatively. Several studies are companion reports of the same underlying trial (e.g. three WISER-trial publications) and are counted as separate records, consistent with how they were published — this is a records count, not a distinct-interventions count. No meta-analysis: this is an evidence map. The ClinicalTrials.gov numbers use a looser full-text registry search — illustrative, not a matched denominator.

Reproducing this

Full pipeline (fetch → dedupe/screen → code → cluster → analyze, per database, plus the merge step) and every intermediate dataset ship in the companion repository's scripts/ and data/ folders, with the full write-up in REPORT.md. Web of Science and Scopus raw exports are not included in the repository (see data-handling note above); only this project's derived, non-abstract data is.

Data: Europe PMC, OpenAlex, ERIC (retrieved 2026-09-26), plus Web of Science and Scopus (institutional access, retrieved 2026-09-27; abstracts not redistributed here per license terms). Pipeline: Python (urllib, scikit-learn TF-IDF/KMeans). This dashboard is a computational first pass intended to scope a full scoping-review protocol, not a finished systematic evidence synthesis.
