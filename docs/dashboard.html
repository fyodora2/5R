Search & screening

Source: Europe PMC REST API (free, no key), field TITLE_ABS, four AND'd concept groups — burnout, digital modality, psychological approach, randomized design. 227 raw hits → 213 unique after exact-key + near-duplicate title dedup (Jaccard > 0.85, catches preprint/published-version pairs) → automated rule-based screening on pubType + design language + occupational-population terms → 85 include / 32 uncertain / 96 exclude.

Limitations

Single database (Europe PMC only — a full protocol needs MEDLINE, PsycINFO, CENTRAL, Scopus/Web of Science). Single-pass computational screening with no second human reviewer or full-text check — the 32 "uncertain" records need manual resolution. Coding is abstract-level only, so technology/instrument/comparator fields are frequently "unspecified" where the abstract simply doesn't say. Clustering silhouette is low (0.021), reflecting a small (n=85), topically homogeneous corpus — read cluster themes qualitatively. No meta-analysis: this is an evidence map, not a pooled effect-size estimate.

Reproducing this

Full pipeline (fetch → dedupe/screen → code → cluster → analyze) and every intermediate dataset ship in the companion repository's scripts/ and data/ folders, with the full write-up in REPORT.md.

Data: Europe PMC (europepmc.org), retrieved 2026-09-26. Pipeline: Python (urllib, scikit-learn TF-IDF/KMeans). This dashboard is a computational first pass intended to scope a full scoping-review protocol, not a finished systematic evidence synthesis.
