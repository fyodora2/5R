# Manuscript

`burnout_scoping_review_paper.docx`: scoping review manuscript (Persian, English abstract), reported according
to PRISMA-ScR with a PRISMA 2020 flow diagram.

**Structure:** abstract (Persian and English); 1 Introduction; 2 Methods (design, eligibility, sources and
search, selection, data charting, registry linkage, synthesis, AI use); 3 Results (selection, characteristics,
temporal trend, evidence map, design and outcome reporting, registry results status); 4 Discussion (main
findings, comparison with previous reviews, implications, strengths and limitations); 5 Conclusion;
declarations; references; appendices A (search strings), B (excluded reports with reasons), C (86 included
trials), D (28 registrations), E (PRISMA-ScR checklist).

**Figures** (`figures/`, generated by `make_figures.py`):

1. `fig1_prisma_flow.png`: PRISMA 2020 flow (databases and registry-linked publications)
2. `fig2_temporal_trend.png`: trials by year of first report and delivery mode
3. `fig3_evidence_map.png`: occupation × intervention approach

**Build:**

```bash
python3 make_figures.py
npm install
node build_paper.js
```

Every number in the text and tables is computed at build time from `data/study_charting.csv`,
`data/master_registry.csv`, `data/registry_linkage.csv` and `data/registry_linked_publications.csv`;
the build stops if the corpus sizes differ from 147 database reports assessed, 89 included reports and
86 trials.

Before submission, fill in the author name and affiliation on the title page.
