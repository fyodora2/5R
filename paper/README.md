# Manuscript

`burnout_scoping_review_paper.docx`: scoping review manuscript (English), reported according to PRISMA-ScR
with a PRISMA 2020 flow diagram.

**Structure:** abstract; 1 Introduction; 2 Methods (design, eligibility, sources and search including the
supplementary search, selection, data charting, registry linkage, synthesis, AI use); 3 Results (selection,
characteristics, development over time, occupational groups and approaches, non-psychological mechanisms,
comparators and outcome reporting, publication of registered trials); 4 Discussion; 5 Conclusions;
declarations; references; appendices A (search strategies), B (excluded reports with reasons), C (107 included
trials), D (28 registrations), E (PRISMA-ScR checklist).

**Figures** (`figures/`, generated by `make_figures.py`):

1. `fig1_prisma_flow.png`: PRISMA 2020 flow (databases, supplementary search, registry-linked publications)
2. `fig2_temporal_trend.png`: trials by year of first report and delivery mode
3. `fig3_evidence_map.png`: occupation x intervention approach

**Build:**

```bash
python3 make_figures.py
npm install
node build_paper.js
```

Every number in the text and tables is computed at build time from `data/study_charting.csv`,
`data/master_registry.csv`, `data/registry_linkage.csv`, `data/supplementary_assessed.json` and
`data/included_reports.json`. The build stops if the corpus differs from 234 assessed reports, 110 included
reports and 107 trials.

Before submission, fill in the author name and affiliation on the title page.
