It displays “Tool Nitrosend MCP” and a send time, along with a public receipt URL, but does not carry the client build, model identifier, server release, or invoked method names. The ChatGPT integration guide describes a hosted app with no local installation or API key: `https://docs.nitrosend.com/integrations/chatgpt`; the quickstart is `https://docs.nitrosend.com/quickstart`.

It should exclude tokens, email addresses, message contents, and OAuth credentials so a future report can establish command and elapsed-time details without guessing.
