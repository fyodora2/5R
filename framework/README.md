# Scoping-review framework

- `SCOPING_REVIEW_FRAMEWORK.md`: the step-by-step method (Persian, with English technical terms), what abstract-only coding can and cannot support, the human/AI division of work, mistakes to avoid and ready prompts for each step.
- `templates/`: starting files for a new review: `criteria.csv`, `search_log.csv`, `ledger_schema.csv`, `charting_schema.csv`, `second_review_sample.csv`, `decision_log.csv`, `config.example.yaml`, and `prisma_counts.py` (validates a ledger and prints the PRISMA flow counts; tested on `data/master_registry.csv`).

Project-specific worked examples: `scripts/final/` (pipeline), `paper/build_paper.js` (manuscript from data), `paper/build_protocol.js`, `paper/build_metadata.js`, `data/DATA_DICTIONARY.md`.
